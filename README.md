
# Interactive CNN Explainer

## Overview

An educational web application designed to explain the
fundamentals of Convolutional Neural Networks (CNNs)
through interactive visualizations and animations.

## Learning Objectives

- Understand how images are represented as pixel values.
- Visualize how convolution filters process images.
- Explore activation functions such as ReLU.
- Understand pooling and feature maps.
- Follow the path from image input to classification.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
